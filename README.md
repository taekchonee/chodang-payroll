# 입구 LED 간판 자동 전환

입구의 CoolLEDX LED 패널(CoolLED1248 앱으로 쓰는 패널) 문구를, 패널 옆 포스기에 설치한 앱이 영업 시간표에 맞춰 자동으로 바꿉니다.

```
포스기의 "LED 간판" 앱 (영업 시간표)
   │  블루투스
   ▼
입구 LED 패널 (16×96)
```

| 폴더 | 내용 |
|---|---|
| `android/` | 포스기에 설치하는 안드로이드 앱 |
| `.github/workflows/build-apk.yml` | GitHub가 앱(APK)을 자동으로 빌드해 릴리스에 올림 |

## 설치

1. 포스기 브라우저에서 아래 주소를 열어 `led-sign.apk`를 받아 설치합니다.
   https://github.com/taekchonee/chodang-payroll/releases/download/led-sign-latest/led-sign.apk
2. **LED 간판** 앱을 열고 **블루투스 권한을 허용**합니다.
3. **절전 예외 설정**을 눌러 허용합니다. (화면이 꺼져도 계속 동작하도록)
4. CoolLED1248 앱을 닫고 **패널 찾기**를 누릅니다. 패널 이름(CoolLEDX-…)과 크기(96×16)가 나오면 준비 완료입니다.
5. **영업 시간표**에서 오픈·마감 시간과 정기 휴무 요일을 확인합니다.

## 앱 기능

- **영업 시간표**: 오픈 시간에 `영업중`, 마감 시간에 `영업종료`로 바뀝니다. 기본값은 09:00~14:30, 월요일 휴무입니다.
- **휴무 앞뒤**: 휴무 전날 마감 후부터 휴무 다음 날 오픈 전까지 휴무 문구가 나옵니다. (일요일 14:30 ~ 화요일 09:00 `월요일 휴무`)
- **오늘만 바꾸기**
  - `재료소진 조기마감`: 누르면 바로 바뀌고, 마감 시간이 되면 `영업종료`로 돌아갑니다.
  - `오늘 임시 휴무`: 오늘 하루만 휴무 문구를 띄웁니다.
  - 둘 다 다음 날이면 자동으로 풀립니다.
- **상태별 문구와 색**: 상태마다 간판 글자와 색(7색)을 바꿀 수 있습니다. 기본색은 모두 흰색입니다.
- **번갈아 표시**: 문구에 `|`를 넣으면 화면을 나눠 보냅니다. `재료소진|조기마감`은 패널이 "재료소진" → "조기마감"을 한 화면씩 번갈아 보여 줍니다. 모든 화면은 가운데 정렬입니다.
- **직접 보내기**: 아무 문구나 보냅니다. 다음 시간표 전환 때까지 유지됩니다.
- **세로 설치**: 기본은 세로입니다. CoolLED 앱의 270° 회전과 같은 방식(세로 A)으로 글자를 하나씩 눕혀 보냅니다. 한 화면에 6글자, 공백은 반 글자 간격입니다. 기본 문구는 `영 업 중`, `영업 종료`, `월요일 휴무`입니다.
- 한 화면에 들어가는 문구는 가운데 고정, 긴 문구는 자동으로 흐르게 표시합니다.
- 포스기가 켜지면 앱이 자동으로 시작되고 **지금 시각에 맞는 문구로 바로 맞춥니다.**

## 알아둘 점

- 시간표대로 바꾸려면 **그 시각에 포스기가 켜져 있어야** 합니다.
- 패널에는 한 번에 한 기기만 연결됩니다. 앱은 문구를 보낸 직후 연결을 끊지만, CoolLED1248 앱이 패널에 붙어 있으면 전송이 실패할 수 있습니다. 실패하면 2분 뒤 다시 시도합니다.

## 만든 방식

글자는 16×16 한글 도트 글꼴 [Neo둥근모](https://neodgm.dalgona.dev/) (OFL-1.1, `android/app/src/main/assets/fonts/neodgm-LICENSE.txt`)로 그립니다. CoolLED 앱처럼 글자가 16칸을 채우고, 굵게는 획을 1칸 더 찍습니다.

패널 통신 방식은 공개 드라이버 [coolledx](https://github.com/UpDryTwist/coolledx-driver) (MIT)를 코틀린으로 옮겼습니다.
APK는 고정된 공개 디버그 키로 서명합니다. 업데이트 설치가 가능하도록 하기 위한 것이며, 이 저장소의 릴리스에서만 받아 설치하세요.

# 서빙 표시 · 주방 화면(KDS)

포스기(이지포스) 화면 위에 서빙 순서를 띄우고, 같은 주문을 주방 태블릿에 대기열로 보여 줍니다. 이지포스는 고치지 않고 **화면을 읽기만** 합니다(안드로이드 접근성). 이지포스에서 누르는 것은 "서빙완료 직후 열린 주문 화면의 X" 하나뿐입니다.

| 폴더 | 내용 |
|---|---|
| `android/servemark/` | 포스기에 설치하는 "서빙 표시" 앱 (주방 화면 서버 포함) |
| `config/kds.html`, `config/settings.json` | 주방 태블릿 화면, 설정 (설치 없이 반영) |

## 설치

1. 포스기 크롬에서 받아 설치합니다. (Play 프로텍트가 막으면 Play 스토어 → Play 프로텍트 → 설정에서 "앱 검사"를 잠시 끄고 설치)
   https://github.com/taekchonee/chodang-payroll/releases/download/led-sign-latest/serve-mark.apk
2. 포스기 **설정 → 접근성 → 서빙 표시**를 켭니다. (한 번만. 재부팅·업데이트 후에도 유지)
3. 주방 태블릿에 **주방 화면** 앱을 설치하고 엽니다. 같은 와이파이에서 포스기를 자동으로 찾고, 화면이 계속 켜져 있으며 알림음도 바로 납니다. (크롬으로 서빙 표시 앱에 나오는 주소를 열어도 됨)
   https://github.com/taekchonee/chodang-payroll/releases/download/led-sign-latest/kitchen.apk
4. 주방 화면을 한 번 눌러 알림음을 켜 둡니다. 태블릿 화면 꺼짐 시간은 길게 해 둡니다.

## 홀 포스기 화면

- 주문 있는 테이블 칸에 **서빙 순서 번호**, 1번 테이블에 빨간 **다음 서빙**, 포장0 아래에 **서빙 대기 N / 남은 서빙 없음**
- **서빙완료 표시**: 테이블 칸의 메뉴 글씨를 길게 누르거나, 주문 화면의 '할인·서비스' 자리에 뜨는 초록 버튼. 다시 하면 해제
- 서빙을 끝낸 테이블에 **추가 주문**이 들어오면 서빙완료가 풀리고 맨 앞으로
- 결제하면 표시가 자동으로 지워짐. 포장은 순서에서 제외
- 주방에서 조리완료 후 1분이 지나도 서빙완료가 안 되면 칸에 **서빙 확인** 깜빡임, 3분이 지나면 자동 서빙완료

## 주방 화면

- 조리 순서대로 테이블 카드. 큰 시간은 최초 주문부터의 경과(5분 주황, 10분 빨강)
- **추가 주문**은 구분선 아래에 `+메뉴 (mm:ss)`. 조리완료 뒤 들어온 추가는 맨 앞 "추가 주문" 카드
- **조리 불필요**(주류·음료·공기밥·할인)는 카드 아래 작은 글씨, 이것만으로는 카드가 생기지 않음. **초당순두부**는 살짝 흐리게
- **제육불고기**는 화면 위에 대기 중 합계(묶음 조리)
- **조리완료** → 아래 서빙 대기 줄로 (되돌리기 가능) → 홀에서 서빙완료하면 사라짐
- **취소**: 메뉴 취소는 취소선, 전체 취소는 빨간 "주문 취소" 카드(1분 30초), 경고음
- **메뉴 변경**(조리완료 뒤)은 "변경" 카드, **테이블 이동**은 카드가 그대로 옮겨지고 "N번→이동" 표시
- 메뉴 분류(조리 불필요·흐리게·묶음 조리)는 `Kitchen.kt` 맨 위 목록에서 바꿉니다.

## 알아둘 점

- 메뉴는 홀 테이블 칸에 보이는 글씨로 읽습니다. 메뉴가 아주 많아 칸에서 잘리면 주방에도 빠질 수 있습니다.
- 결제와 전체 취소는 이지포스의 "주문을 취소하시겠습니까?" 창이 떴는지로 구분합니다.
- 포스기 주소가 바뀌면 주방 화면이 끊깁니다. 공유기에서 포스기 주소를 고정해 두는 것이 좋습니다.
- 주방 화면 서버는 매장 와이파이 안에서 누구나 열 수 있습니다. 손님용 와이파이를 따로 쓰는 것이 안전합니다.

## 주방 방송 (매장주방홈미니 + 주방 직원 폰)

메뉴를 다 읽지 않고, 주방이 움직여야 할 순간에만 짧게 알립니다.
- 새 주문 → "신규주문" / 메뉴 추가·취소 → "메뉴변경 발생" / 전체 취소 → "주문취소" / 테이블 이동 → 말 안 함
- 제육불고기가 다른 테이블에서 이미 조리 대기 중일 때 새 주문에 또 들어오면 → 이어서 "제육 2개 추가"
- 문구는 `config/settings.json`의 `phrases`, `batchFormat`, `batchNames`에서 설치 없이 바꿉니다(빈 문구면 말 안 함).

**매장주방홈미니**: 서빙 표시 앱 → 홈어시스턴트 웹훅 → Edge TTS. `homeassistant/kitchen-announce.yaml` 자동화(볼륨 100%) 필요.

**주방 직원 폰 (주방 알림 앱, staff-alert.apk)**: 홈어시스턴트를 거치지 않고, 매장 와이파이로 포스기에서 문장을 받아 폰 자체 음성으로 읽습니다(유튜브 위에 잠깐 끼어듦).
- 설치: https://github.com/taekchonee/chodang-payroll/releases/download/led-sign-latest/staff-alert.apk
- 처음 한 번: 알림 허용, 배터리 "제한 없음", (삼성) 사용하지 않는 앱 절전 목록에서 빼기
- 매장 와이파이에서만, 받는 시간(기본 08:30~15:30)에만 동작. 권한은 인터넷·알림뿐(앱 첫 화면에 하는 일/하지 않는 일 표시)
- 음성 엔진·목소리·빠르기·미리 듣기, 안내 때만 볼륨 최대(기본 끔), 업데이트 버튼
- 서빙 표시 앱 화면에 "직원 폰 연결: N대" 표시

**직접 방송**: 서빙 표시 앱의 입력칸, 또는 매장 와이파이에서 사장님 폰 크롬으로 `http://포스기주소:8080/say` (자주 쓰는 문구 버튼은 `settings.json`의 `sayPresets`). 홈미니와 직원 폰 양쪽으로 갑니다.

## 업데이트와 설정 (설치 없이 바꾸기)

- **설정·주방 화면은 설치 없이 바뀝니다**: `config/settings.json`(시간 기준·메뉴 분류)과 `config/kds.html`(주방 화면)을 고쳐 올리면, 포스기 서빙 표시 앱이 5분 안에 받아 쓰고 주방 태블릿 화면도 저절로 새로고침됩니다.
- **앱 자체가 바뀔 때만 업데이트**: 각 앱의 **앱 업데이트** 버튼(LED 간판은 설정 탭, 서빙 표시는 첫 화면, 주방 화면은 새 판이 있을 때 오른쪽 아래에 버튼)을 누르고, 설치 창에서 '설치'를 한 번 누르면 됩니다. 처음 한 번은 그 앱의 '출처를 알 수 없는 앱 설치'를 허용해야 합니다.
- 버전 번호는 GitHub가 빌드할 때 자동으로 매깁니다(앱 폴더가 바뀐 커밋 수 + 100). 설정만 바꾸면 버전은 그대로입니다.
