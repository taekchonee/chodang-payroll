# 매장 데이터 자동화

이지포스(EasyPOS) 백오피스(https://smart.easypos.net)에서 매출 데이터를 자동으로 가져오는 프로젝트입니다.

## 현재 단계: 정찰

백오피스가 서버와 어떤 형식으로 데이터를 주고받는지 확인하는 단계입니다.
`recon/recon.py`를 집 PC에서 한 번 실행하면 결과 파일이 만들어집니다.

### 저장되는 것과 저장되지 않는 것
- 저장: 열어본 화면 이름, 조회 요청 형식, 데이터 묶음의 열 이름과 앞쪽 30줄, 백오피스 메뉴 목록
- 저장 안 함: 로그인 요청(암호화된 아이디·비밀번호), 쿠키, 세션 정보

## 집 PC(윈도우)에서 실행하기

1. **파이썬 설치**: https://www.python.org/downloads/ 에서 최신 버전을 받아 설치합니다.
   설치 첫 화면에서 **"Add python.exe to PATH"에 꼭 체크**하세요.
2. **이 저장소 내려받기**: GitHub 저장소 페이지에서 지금 브랜치를 고른 뒤 `Code` → `Download ZIP`으로 받아 압축을 풉니다.
3. 압축을 푼 폴더에서 주소창에 `cmd`를 입력하고 Enter를 누르면 명령 프롬프트가 열립니다. 아래를 차례로 입력합니다.

   ```
   pip install -r requirements.txt
   python -m playwright install chromium
   python recon/recon.py
   ```

4. 브라우저 창이 뜨면 **직접 로그인**합니다.
5. `매출` 메뉴 아래 화면들을 하나씩 열고, 날짜를 **지난 7일** 정도로 정한 뒤 **[조회]** 를 누릅니다.
   아래 화면이 있으면 꼭 열어 주세요.
   1. 영수증별 / 거래별 / 결제 상세 내역
   2. 메뉴별(상품별) 매출
   3. 시간대별 매출
   4. 일자별 매출

   `[엑셀]` 버튼이 있으면 한 번씩 눌러 보셔도 됩니다.
6. 다 마치면 명령 프롬프트 창에서 **Enter**를 누릅니다.
7. `recon_output` 폴더에 `capture_날짜_시각.json` 파일이 생깁니다. 이 파일을 **Claude 채팅에 첨부**해 주세요.

> ⚠️ 이 저장소는 공개(public) 저장소입니다. 결과 파일에는 매출 일부가 들어 있으니 **GitHub에 올리지 마세요.**
> (`.gitignore`에 `recon_output/`이 들어 있어 git으로는 올라가지 않습니다.)
