# 입구 LED 간판 자동 전환

입구의 CoolLEDX LED 패널(CoolLED1248 앱으로 쓰는 패널) 문구를, 패널 옆 포스기에 설치한 앱이 영업 시간표에 맞춰 자동으로 바꿉니다.

```
포스기의 "LED 간판" 앱 (영업 시간표)
   │  블루투스
   ▼
입구 LED 패널 (16×96)
```

| 폴더 | 내용 |
|---|---|
| `android/` | 포스기에 설치하는 안드로이드 앱 |
| `.github/workflows/build-apk.yml` | GitHub가 앱(APK)을 자동으로 빌드해 릴리스에 올림 |

## 설치

1. 포스기 브라우저에서 아래 주소를 열어 `led-sign.apk`를 받아 설치합니다.
   https://github.com/taekchonee/chodang-payroll/releases/download/led-sign-latest/led-sign.apk
2. **LED 간판** 앱을 열고 **블루투스 권한을 허용**합니다.
3. **절전 예외 설정**을 눌러 허용합니다. (화면이 꺼져도 계속 동작하도록)
4. CoolLED1248 앱을 닫고 **패널 찾기**를 누릅니다. 패널 이름(CoolLEDX-…)과 크기(96×16)가 나오면 준비 완료입니다.
5. **영업 시간표**에서 오픈·마감 시간과 정기 휴무 요일을 확인합니다.

## 앱 기능

- **영업 시간표**: 오픈 시간에 `영업중`, 마감 시간에 `영업종료`로 바뀝니다. 기본값은 09:00~14:30, 월요일 휴무입니다.
- **휴무 앞뒤**: 휴무 전날 마감 후부터 휴무 다음 날 오픈 전까지 휴무 문구가 나옵니다. (일요일 14:30 ~ 화요일 09:00 `월요일 휴무`)
- **오늘만 바꾸기**
  - `재료소진 조기마감`: 누르면 바로 바뀌고, 마감 시간이 되면 `영업종료`로 돌아갑니다.
  - `오늘 임시 휴무`: 오늘 하루만 휴무 문구를 띄웁니다.
  - 둘 다 다음 날이면 자동으로 풀립니다.
- **상태별 문구와 색**: 상태마다 간판 글자와 색(7색)을 바꿀 수 있습니다. 기본색은 모두 흰색입니다.
- **번갈아 표시**: 문구에 `|`를 넣으면 화면을 나눠 보냅니다. `재료소진|조기마감`은 패널이 "재료소진" → "조기마감"을 한 화면씩 번갈아 보여 줍니다. 모든 화면은 가운데 정렬입니다.
- **직접 보내기**: 아무 문구나 보냅니다. 다음 시간표 전환 때까지 유지됩니다.
- **세로 설치**: 기본은 세로입니다. CoolLED 앱의 270° 회전과 같은 방식(세로 A)으로 글자를 하나씩 눕혀 보냅니다. 한 화면에 6글자, 공백은 반 글자 간격입니다. 기본 문구는 `영 업 중`, `영업 종료`, `월요일 휴무`입니다.
- 한 화면에 들어가는 문구는 가운데 고정, 긴 문구는 자동으로 흐르게 표시합니다.
- 포스기가 켜지면 앱이 자동으로 시작되고 **지금 시각에 맞는 문구로 바로 맞춥니다.**

## 알아둘 점

- 시간표대로 바꾸려면 **그 시각에 포스기가 켜져 있어야** 합니다.
- 패널에는 한 번에 한 기기만 연결됩니다. 앱은 문구를 보낸 직후 연결을 끊지만, CoolLED1248 앱이 패널에 붙어 있으면 전송이 실패할 수 있습니다. 실패하면 2분 뒤 다시 시도합니다.

## 만든 방식

글자는 16×16 한글 도트 글꼴 [Neo둥근모](https://neodgm.dalgona.dev/) (OFL-1.1, `android/app/src/main/assets/fonts/neodgm-LICENSE.txt`)로 그립니다. CoolLED 앱처럼 글자가 16칸을 채우고, 굵게는 획을 1칸 더 찍습니다.

패널 통신 방식은 공개 드라이버 [coolledx](https://github.com/UpDryTwist/coolledx-driver) (MIT)를 코틀린으로 옮겼습니다.
APK는 고정된 공개 디버그 키로 서명합니다. 업데이트 설치가 가능하도록 하기 위한 것이며, 이 저장소의 릴리스에서만 받아 설치하세요.
